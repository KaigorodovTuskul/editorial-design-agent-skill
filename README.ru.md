# Editorial Design — Agent Skill и издательский движок

**v0.2.0.** Агент создает авторские HTML/CSS/SVG-композиции для финансовых отчетов и презентаций, вместо заполнения девяти стандартных шаблонов. Движок экспортирует PDF и **гибридный PPTX**: дизайн страницы одним статичным изображением, поверх — редактируемый текст и числовые показатели.

## Что изменилось

- Свободная журнальная верстка: агент самостоятельно проектирует каждый слайд с учетом содержания и общего визуального языка.
- Поддержка выбранной цветовой системы Arctic Editorial и шрифтов Geologica Roman (по умолчанию), Geist, IBM Plex Sans, Onest, Manrope. Перед новым интерактивным проектом скилл просит выбрать палитру и шрифт один раз.
- Hallmark — обязательная внешняя зависимость с зафиксированной ревизией, реальным запуском `sloplint --render` и журналом результатов. Если он не установлен, выпуск блокируется.
- Обязательные два прохода визуальной проверки, третий только при существенных проблемах. Запуск сабагентов и `/goal` зависит от возможностей конкретного харнесса.
- Новый экспорт PowerPoint сохраняет выравнивание текста, учитывает установленный шрифт и проверяет PPTX после обратного рендеринга в LibreOffice.
- **Согласованная пара PDF/PPTX**: после прохождения сравнения итоговый PDF создается из проверенного PPTX тем же рендерером. Исходный браузерный PDF сохраняется отдельно.

## Запуск

```bash
pip install -r requirements.txt
npm install
npm run setup:hallmark
python examples/editorial-reference/build_example.py
node bin/editorial.mjs build-html examples/editorial-reference --out outputs/arctic-case --allow-unverified
node bin/editorial.mjs verify outputs/arctic-case
npm run check
```

В каталоге `examples/editorial-reference/` — семь оригинально сверстанных HTML-страниц на основе демонстрационного материала стратсессии. Это **не универсальные шаблоны**, а пример того, какой код должен создавать агент. `--allow-unverified` разрешает только сборку черновика, не присваивает ему статус готового инвестиционного документа.

## Границы точности

Верифицированная пара PDF/PPTX совпадает при рендеринге **тем же LibreOffice**. Другое издание Microsoft PowerPoint или отсутствующий на компьютере шрифт могут изменить вид нативного редактируемого текста. Математическую идентичность пикселей для всех Office-рендереров гарантировать нельзя. Программа проверяет расхождения, но из этого не следует, что любой визуально заметный дефект обнаружится автоматически. Диаграммы и декоративные элементы статичны: изменение числа в PPTX не пересчитывает связанные графики.

**Статус демонстрации — NOT_READY**: в используемой среде не установлен Geologica и не удалось скачать Hallmark; исходные значения иллюстративны. Скилл не утверждает обратного.
