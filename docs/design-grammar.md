# Editorial art direction — v0.2, not a fixed template library

Use the user's reference deck as a **quality benchmark**, not as a rigid palette or pixel template.

The model begins with the claim and the evidence. For the demonstration strategy narrative, the claim sequence is: adverse baseline → model pivot → financial drivers → scenario comparison → profit bridge → decision. Each slide should be designed around its own communication priority while sharing precise typographic and graphic DNA.

**Useful editorial vocabulary, not layout classes:** monumental display type; two-column asymmetric body; negative space; dark fact rail; ledger/timeline; number as editorial hero; long-form horizontal comparisons; sparse label + accurate data graphics; notched rule; contrastive dark closing page; typographic punctuation as compositional structure. Choose forms based on meaning and avoid repeating the same silhouette. The agent can invent another form if it is more effective.

**Craft checklist:**

- Text hierarchy should explain importance at a glance; not every page has the same header/subtitle/chart/cards recipe.
- Use negative space to make the strongest statement stronger, not as an excuse for thin content.
- No invented diagram/data connections. Financial bridges must reconcile or explicitly flag mismatched/rounded totals.
- Keep system-level page margins and baseline logic consistent while permitting nonuniform columns and deliberate breaking of alignment.
- Primary surfaces should be quiet and supportive; choose one focal chromatic contrast per page. Avoid blue-to-purple glowing mesh-gradient clichés.
- Full source facts, unit labels, periods and caveats must remain readable. PDF/PPTX parity governs editable typography, not the originality of the HTML layouts.

The example under `examples/editorial-reference/` is **hand-art-directed independent HTML**, not a set of runtime templates. Real agent tasks should author new compositions from the user's own content and visual identity.
