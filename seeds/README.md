# Visual seeds

Visual seeds are reusable, locally stored **source assets** and design references. They are optional visual vocabulary, not a slide-template library. The agent is encouraged to design original compositions and new SVG assets based on the brief. A theme's seed folder contains original SVGs, a manifest of provenance, and design tokens. Never mix an externally sourced client's corporate logo with generic seed art.
